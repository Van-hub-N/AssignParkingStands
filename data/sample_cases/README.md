# 样例案例说明

完整数据集体积约 59 MB，提交包只保留 13 个代表性案例，覆盖小、中、大三种规模，并覆盖回溯法、分支限界法的精确组、可扩展性组和大规模受限组。完整 10000 个案例可由：

```bash
./build/bin/generate_cases --out-dir data
```

重新生成。样例文件与完整数据集的编号、二进制格式完全一致，可以直接用 `dump_case` 查看：

```bash
./build/bin/dump_case 7000 --data-dir data/sample_cases
```
